# My Game

Originales Retro-MMORPG-Projekt.

## Aktueller Stand
- Klassenloser Charakter mit 5 Attributen
- Level, XP, HP, Gold und freie Attributpunkte
- Drei Regionen: Dämmerhain, Ravenfels, Steinmark
- NPC, erste Quest, Gegner, Kampf und Beute
- Inventar, Ausrüstung, Zauber- und Weltansicht
- WASD, Pfeiltasten und iPad-Touch-Steuerung
- Statische Veröffentlichung über GitHub Pages
